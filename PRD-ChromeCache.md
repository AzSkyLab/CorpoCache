# **Project Requirements Document: Chrome Cache**

The following table outlines the detailed functional requirements of the Chrome Cache website.

| Requirement ID | Description                                   | User Story                                                                                                   | Expected Behavior/Outcome                                                                                                                      |
|----------------|-----------------------------------------------|--------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| FR001          | Four Distinct Sections                        | As a user, I want the site to have sections for Credit Cards, Monthly Bills and Expenses, Income, and Savings Estimator. | The site should display four main sections: Credit Cards, Monthly Bills and Expenses, Income, and Savings Estimator.                           |
| FR002          | Credit Card Entry and Calculations            | As a user, I want to enter my credit cards with details and see utilization and payment suggestions.         | Users can enter Date Opened, Credit Limit, and Current Balance for each card. Each card displays utilization, amounts to pay to be under 29% and 9%, and a total for all cards. |
| FR003          | Monthly Bills and Expenses Management         | As a user, I want to enter monthly bills, amounts, and due dates, and mark them as paid.                    | Users can enter bills with amount due and date, label each for the 15th or last day paycheck, and mark as paid for the month.                  |
| FR004          | Reset for New Month                           | As a user, I want to reset the page for a new month.                                                        | A button is provided to reset all relevant data for a new month.                                                                               |
| FR005          | Income Entry and Tax Breakdown                | As a user, I want to enter my salary, deductions, and see a tax breakdown.                                  | Users can enter yearly salary, 401k %, ESPP %, insurance costs, and bonus %. The site breaks down taxes by federal, OASDI, Medicare, and state.|
| FR006          | Savings Estimator                             | As a user, I want to estimate my monthly savings based on my income and expenses.                           | The site calculates remaining monthly cash based on income and expenses, and stores the value for each month.                                  |
| FR007          | Persistent Data Storage                       | As a user, I want my data to be saved and persistent.                                                       | All user data is stored in a database and persists across sessions.                                                                            |
| FR008          | Technology Stack                              | As a developer, I want to use HTML, CSS, and Typescript.                                                    | The site is built using HTML, CSS, and Typescript.                                                                                             |
| FR009          | Hosting on Azure App Service                  | As a developer, I want the site to be hosted on Azure App Service.                                          | The site is deployed and accessible via Azure App Service.                                                                                     |
| FR010          | Data Storage in Azure Cosmos DB               | As a developer, I want to store data in Azure Cosmos DB.                                                    | All persistent data is stored in Azure Cosmos DB.                                                                                              |
